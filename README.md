*by flakalet. Intended for 26.3\**

put this both into your datapack directory and your resourcepack directory (or, if you're a server, link [this](https://github.com/svntythsnd/heartrobber/releases/latest/download/raw.zip) as your server resource pack)

The `/function give:<namespace>/<id>` module provides functions for getting canonical custom/modified items.

Use `/data merge storage heartrobber:config {letterCooldown:<n>}` to set the letter delivery timeout to `<n>` in-game days (default is 7)

To get the version of Heartrobber currently installed as a *resourcepack*, check the description in the resourcepack list.

To get the version of Heartrobber currently installed as a *datapack* (OP only), run the command `/function heartrobber:v`

To show the amount of hearts each player has in the player list, use `/scoreboard objectives setdisplay list heartrobber_health`
